# Company Profile: MiniMax

> Last updated: 2026-08-08

## Basic Info

- **Full name**: MiniMax Group Inc. (稀宇科技)
- **Founded**: 2021
- **Founder**: Yan Junjie (闫俊杰)
- **Type**: AI Startup (one of China's 6 "AI Tigers")
- **Headquarters**: Shanghai, China
- **Listing**: Hong Kong Stock Exchange (HKEX: 0100.HK), listed January 2026
- **Stock history**: Peak HK$1,330 (Mar 2026) → Low HK$186 (Jul 2026) → ~HK$247 (Aug 2026). -86% from peak.

## AI Division

- **Team name**: MiniMax (same as company)
- **Consumer products**: **Talkie** (AI character app), **Xingye** (AI character app), **Hailuo AI** (video generation)
- **Enterprise API**: MiniMax API
- **Open source strategy**: Limited — primarily closed-source commercial products
- **Commercial model**: Consumer apps (AI companions) + video generation API + enterprise API

### Stock Collapse Drivers

1. Anthropic distillation accusations (reputational damage)
2. M3 permanent price cut (revenue concerns)
3. Low consumer margins (AI companion apps not profitable)
4. New AI companion regulations (regulatory risk)
5. Significant annual losses (financial unsustainability)
6. Moonshot IPO preparations (competitive pressure)
