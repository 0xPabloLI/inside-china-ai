## 一、算法世界的底层逻辑

### 注意力就是钱

对于任何平台——抖音、小红书、YouTube、B站、Twitter——你的注意力就是它的收入。

逻辑链：
- 你能帮平台留住用户、延长留存时间 → 平台免费给你流量。这是"自然流"。
- 你不能给平台带来注意力回报 → 你的每一分曝光都得花钱买（投流/抖加/Dou+）。
- 你的算力消耗、用户停留时长——平台都在算账。

小红书最恶劣：投完流之后不继续投 → 自然流也会被砍。算法已经标记了你是一个"不投流就没流量"的账号。抖音同理。

一句话：算法就是弱肉强食。这是数字竞技场的核心——注意力经济。每个人都是角斗士。

### 账号会"脏"——而且很难救

一个号如果历史内容数据差（没人看、完播率低、互动少），平台已经给它贴了标签：下次你发新内容，算法回忆"这号之前的东西没人看 → 继续不给流量。"

更致命的是：你之前发过的某个素材没有流量。你把那个素材重新剪一遍再发出来——算法仍然记得"这是个烂素材"，继续不给流量。

结论：要么重开新号，要么放弃这个平台。脏号不值得花时间救。

### B站旧号的问题更复杂

B站旧号脏了的原因可能有两个：之前的内容太水没人看；号本身可能被买过/有过问题——有个学生自己的作品在旧号上能跑几万播放，同样的视频换到一个全新的陌生号上——零播放。说明旧号本身被平台标记了。

结论：如果旧号数据一直起不来，新开一个号可能比救旧号快得多。

### Twitter 不一样——但不能放着不管

Twitter 不会像小红书一样永久"废号"。但如果你一个月都不怎么发，算法也会降低你的权重。

706 的 Twitter 目前掉粉中。之前的日更策略失败了——不是日更本身错，而是日更的内容没有数据反馈，"为了发而发"反而加速了算法的负面判断。

### 跨平台投流：好作品在哪里都能爆

好作品在 A 平台爆了 → 证明内容本身有价值。B 平台冷启动可能前十个人刚好睡着了、没互动。此时投流是值得的——给一千个人看，真正的数据就出来了，算法就会接手。

这和"流量池"是两个概念。流量池的逻辑是：第一波推送给十个人 → 完播率不够 → 平台不再继续推。投流是跳过第一波，直接给算法足够样本做判断。

## 二、内容公式：钩子 → 共情 → 获得感 → 升华

乱码给了一条四层公式，从短视频到中长视频到播客都适用。这是他上课教的核心框架。

### 第一层 · 钩子（前 10 秒最重要）

- 必须有一个戏剧化的东西放在最前面。
- 封面给眼球，标题给算法（GEO/SEO）。标题不重要——没人看你的标题。大家只看封面。
- 检验方法：同一个视频换标题不换封面 → 播放量没差别。证明标题不驱动点击。
- 前 10 秒要额外设计：更多的梗图、更多的钩子、更多视觉冲击。
- 第一个画面绝对不能普通。参考"整理背包"类短视频：第一帧把所有东西铺满在地上——视觉冲击极强，16 万播放。

### 第二层 · 共情

- 让观众感觉"你和我是一伙的"、"你不是敌人，你是自己人"。
- 不是讲道理——是讲"我也有这个困惑"、"你也被这个东西困扰过对吧"。
- 老登出镜 → 大家不会共情。"你要让别人觉得这个人跟我一样。"
- 核心：钩子留住人 → 共情让人感觉你和他是一伙的。

### 第三层 · 获得感

- "我关注你是有好处的"——这是涨粉的核心。
- 你给观众点通了某个东西 → 他就有收获感 → 他关注你。
- 获得感不一定是"干货"——情绪共鸣、视角转换、"原来是这样"的感觉，都算获得感。
- 你做的东西如果让人看完觉得"学到了"、"被理解了"、"看到了不一样的角度"——任何一个都行。

### 第四层 · 升华

- 升华可以提升前面每一层的功力：让钩子变强、让共情变深、让获得感变厚。
- 检验标准：一个作品连几万播放都没有 → 你目前的方法论就是错的。用心做的还不如随手拍的 → 方法论错了。换方法。

## 三、四条实操法则

### 法则一：封面给眼球，标题给算法

标题不重要——没人看标题，大家只看封面。标题是搜索和推荐算法的食物（GEO/SEO），封面是活人眼球的食物。封面每个平台要单独做。B站中文封面 ≠ YouTube 英文封面。

### 法则二：一鱼多吃，但不要走极端

花 100 分钟做一份内容，多发一个平台只花 10 分钟。收益可能是 100 倍。不要左边做一盘菜、右边做一盘菜。做一锅大菜，分盘上。但别走极端——不是所有内容适合所有平台。画幅建议：4:3。

### 法则三：不要日更

你目前的水平可能是够日更的，但你的精力不够。三天干不完一个东西 → 说明立项本身有问题，不是执行速度的问题。不要过度内耗。要算时间分配的收益。

### 法则四：元素迭代法——石墨烯 + 鸟粪

这是科学实验的方法，不是玄学：

1. 第一轮：发现石墨烯好用 → 石墨烯 + 一切组合
2. 第二轮：发现石墨烯 + 鸟粪更好 → 石墨烯 + 鸟粪 + 新变量
3. 第三轮：发现石墨烯 + 鸟粪 + 电视机更好 → 继续加新变量

所有好的留下，所有不好的淘汰。每一轮只换一个元素。火的元素可以拆分组合。ABCD 四个元素中 B 和 D 火 → 保留 BD，换 AC → 测试。"媒体终究是数据说话的事。"

## 四、三种内容品类

### 品类 A：热点 + 大咖解读 ⭐⭐⭐

最快上手、成本最低、最适合冷启动。

逻辑链：请不到马斯克本人 → 解读马斯克也有三层流量。请不到齐泽克本人 → 找中国学者解读齐泽克 → 四层流量。

操作步骤：
1. 每天扫描热点（多平台——推特、YouTube 热的内容也要看）
2. 看哪些热选题能关联上 706 的讨论/语料/活动
3. AI 分析热点内容的核心观点 → 你出镜解读，2 分钟就够了
4. 中间自己加梗、加梗图
5. 进阶：邀请嘉宾一起解读（用竞标制，不是轮流来）

选题举例：诺兰《奥德赛》采访（Twitter 近两千万播放）；赫拉利新观点；Ray Dalio 经济预测。

### 品类 B：社区生活短剧 / 共居切片 ⭐⭐

利用 706 已有的素材和日常，不需要额外生产成本。

参考方向："整理背包"类（第一帧铺满→视觉冲击，16 万播放）；"社区主理人的一天"；"低收入中国青年的一天在社区"；共居迷你剧；"社区温情时刻"。

怎么拍：微距（小的故事）；有剧本；台词用 AI 改一下；第一个画面绝对不能普通。

### 品类 C：播客 / 嘉宾对谈 ⭐

不抱流量幻想，但必须做。

为什么流量不会好：播客受众是开车的人。地铁上的人刷短视频。听完最好的就退出了。

但为什么必须做：
1. 嘉宾闭环：请嘉宾来聊 → 录下来就是素材 → 有了长期关系
2. 知识库积累：嘉宾的观点、表达全部进入本地 RAG
3. 素材现成：706 有这么多采访和活动
4. 单集制就行：不要系列化
5. 心理预期：做好两位数播放的准备

## 五、热点回应管线：三段论

### 阶段一：热点搜索

自动扫描多平台当前最火的内容。不只国内——推特、YouTube 热的也要纳入。

### 阶段二：本地 RAG 精确匹配（核心）

Indexing 比模型重要。不要把所有文字稿塞进大模型。先用便宜模型跑大量子代理 → 给每段文字稿写摘要。检索时检索摘要层，不是全文。图片/视频的 embedding 提前做好 → 文字关键词触发 → 素材精准返回。

### 阶段三：AI 自动剪切片

基于语义匹配的精确剪辑，不是简单切时间戳。"剪视频哪个 AI 都可以干——但剪得好不一样。你得抓住重点。"

三段论打通 = 一个真正的视频员工。

## 七、完整例子：从共鸣到升华

乱码用他自己的阿里云演讲举了一个完整的结构范例：

**第一步 · 共鸣开头**：> "小时候家长告诉你——考上大学就好了。考上大学之后跟你说——考研就好了。考研之后——考公就好了。考公之后——还是不好。" → 让观众感觉"对，我也经历过这个。"

**第二步 · 解释原因**：> "为什么我们一直生活在'彼岸幻觉'里？因为在过去，我们是后发国家——前面有苏联可以抄、美国可以抄、欧洲可以抄。" → 观众感觉"对，你说得对，我学进去了。"

**第三步 ·'给出证据**：> "但你看——美国现在是第一，中国是第二。你有没有听说过'欧洲大魔仙'？——没有。因为前面已经没有大魔头了。" → 观众想"确实——我没听说过。"

**第四步 · 升华**：> "迷茫——它其实也是一种自由。在被迫的环境下你没有选择的时候，是迷茫。只有你有选择的时候，才会迷茫。" → 钩子 → 共情 → 获得感 → 升华，四层全中。

## 八、不要做什么

1. **不要为了发而发。** 如果你的号一点流量都没有，为了发一条内容而发 = 把号砸了。
2. **不要把所有嘉宾素材直接发出去。** 嘉宾素材是知识库——它一定要变成某种东西的"结合"和"回应"才行。
3. **不要花大量时间做低回报的事。** 算时间分配。
4. **不要一次把所有素材全用了。** "一次全用就浪费了——分开用。"
5. **不要在账号没数据的时候投小红书流。** 你投完不投了，自然流就没了。
