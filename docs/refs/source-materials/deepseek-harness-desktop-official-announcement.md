## 更顺畅的日常办公与开发体验

本次更新优化了文件展示、内容预览和代码变更展示体验，完善了自动化任务的设置与管理，并提供多种工作过程展示方式，方便你查看任务进展、了解执行步骤和排查问题。

你可以提供文档、表格或 PDF 文件，让 DeepSeek Harness 整理资料、分析数据、生成图表或制作演示文稿，也可以让它修改项目、运行代码，协助完成开发任务。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

生成的文件与每轮代码变更会集中展示在对话中。你可以在侧栏预览文件内容、查看代码及其修改差异，并通过对话继续提出修改要求，也可以使用本地应用打开文件，进一步编辑。

本次更新还内置了可按需开启的自动化任务插件。在侧栏的插件管理页面中开启自动化任务功能后，你可以将重复性工作设为按计划执行的定时任务，并查看任务运行记录、调整执行频率与任务指令。

此外，针对不同用户的工作需求，我们提供了不同信息展示程度的灵活选择，包括 Agent 工作步骤的展示方式，以及不同的功能和信息在界面中的详略程度，方便你根据工作习惯选择更适合的工作界面。

## 更方便的插件管理

DeepSeek Harness 桌面端延续“一切皆插件”的设计理念：小到一个工具，大到整个交互界面，都能以插件的方式融入其中。你可以按需添加插件，自由组合能力，让 Harness 更贴合你的工作方式。

新版本中新增了插件管理页面：安装插件无需命令行，直接在插件管理页面中输入插件包名（即 npm 包名）即可完成安装，你也可以在同一页面中停用、卸载插件，以及查看插件的介绍与来源。

## 未来产品路线

在使用 DeepSeek 官方 API 的用户群体中，DeepSeek Harness 在日均活跃用户、日均会话数等口径上都已成为最受 DeepSeek 用户欢迎的 Coding Agent 产品。

接下来，DeepSeek Harness 团队将持续改善从上手到完成各类任务的用户体验，包括：改善沙箱功能与安全性、完善智能体团队功能的效果与易用性、加入个性化的长期记忆、实现浏览器与其它 GUI 软件的自动化操作、支持远程与移动端使用、探索会话分享与多人协作。我们会持续加入更多按需开启的实验性功能，并将经过打磨和验证的功能默认开启。

DeepSeek Harness 也将与 DeepSeek 模型共同进化。我们会持续针对新模型优化与适配 DeepSeek Harness，在模型训练中优化在 DeepSeek Harness 中的实际表现，在模型研究中为 DeepSeek Harness 的创新产品功能提供支持。

此外，第三方插件是 DeepSeek Harness 用户体验中最具特色且不可缺少的一部分。按照官方模型 API 用户口径统计，约 60% 的 DeepSeek Harness 用户使用了第三方插件。

DeepSeek Harness 团队将持续支持第三方插件生态的繁荣发展，改善第三方插件的发现、获取和管理体验，并建设官方插件市场。我们也将推动插件 API 趋于清晰和稳定，在将来减少和尽量避免破坏性更新，提升插件 API 的前向和后向兼容性，用多种技术手段降低插件开发者跨版本适配的成本。

我们希望让智能融入更多人的日常工作和生活，也期待更多插件开发者参与“一切皆插件”的生态，共同拓展智能的应用边界，一起定义开源、开放、可复用、可组合的智能产品。
