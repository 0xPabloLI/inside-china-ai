## 0. 用户提供线索（原始）

据报道，DeepSeek 创始人梁文锋近期密集关注具身智能领域，并与多位该领域创业者交流，探讨机器人、大模型与现实世界交互等方向。据知情人士透露，梁文锋正在考虑 DeepSeek 进入具身智能领域的可能性，可能会亲自组建团队下场研发，也可能通过投资相关企业切入。此前，梁文锋已投资宇树科技，另据彭博社报道，DeepSeek 计划领投腾讯前 AI 科学家胡瀚创立的机器人公司 Winverse AI。（来源：新浪科技）

## 1. 一手来源：凤凰网科技独家（2026-10-12）

- **URL**: https://original.ifeng.com/c/8x8CSYp7qr4
- **标题**: 独家｜梁文锋密集交流具身智能创业者，DeepSeek 考虑亲自下场或投资入局
- **作者**: 董雨晴、赵子坤（编辑：董雨晴）
- **核心事实**（凤凰网科技从多个不同信源处了解）：
  1. 梁文锋近期密集关注具身智能领域，与多位该领域创业者交流，探讨机器人、大模型与现实世界交互等方向。
  2. 梁文锋正考虑 DeepSeek 是否进一步进入具身智能：方案包括**亲自组建团队下场研发**，或**通过投资相关企业切入**。
  3. 引述知情人士：「梁文锋在这个领域也不是很有经验，所以也在密集学习」。
  4. 此前梁文锋已投资宇树科技；**就在宇树科技上市前夕，梁文锋曾出资 1.41 亿突击入股**。
  5. Winverse AI：成立仅数月，计划通过种子轮融资筹集数千万美元，**投后估值预计约 4 亿美元**；DeepSeek 已同意牵头本轮融资，美团旗下龙珠投资（Long-Z Investments）等机构也已作出投资承诺。
  6. **反向证词（重要）**：凤凰网科技从多位行业人士处了解到，「该公司不能算严格意义上的具身智能公司，更偏底层 infra，做模型加速相关」。
  7. **触发变量**：GPT-6 带来的压力。GPT-6 Astra 在一项机器人控制任务中的成功率达 **95%**，高于 **Fable 5.1 的 40%**；多个测试 demo 显示 GPT-6 在具身智能领域实现了令行业惊讶的执行效果。接近 DeepSeek 的人士透露，梁文锋近期曾表达 DeepSeek 与 GPT-6 相比在部分能力维度仍存在差距。
  8. 另一行业人士：DeepSeek 考虑具身智能并不令人惊讶，**智谱与 Kimi 等 AI 公司均有具身智能相关业务储备**。
  9. OpenAI 动向（行业人士）：除 GPT-6 外，OpenAI 正在单独训练一个具身智能基座模型。引述：「GPT-6 看起来厉害，要颠覆具身了，但它拿起一个杯子要 40 分钟，大家对具身的要求还是太低了」。
  10. 中国市场具身智能公司举例：银河通用、星海图、德塔智能。
  11. 两条路径分析：直接组建团队（需补机器人硬件、运动控制、数据采集能力）vs 投资/战略合作（模型公司提供「大脑」，机器人企业提供「身体」）。
  12. 一位业内人士：大模型公司进入具身智能，并不只是为了做机器人产品，而是在争夺未来 AI 能力的重要入口。

- **URL**: https://thenextweb.com/news/deepseek-winverse-ai-robot-seed-round
- 补充事实：

  5. DeepSeek 此前在宇树科技上海上市时买入其股份。
  6. DeepSeek 接近完成至少 **120 亿美元**融资（腾讯参与），计划 **2027 年初上市**；资金主要用于模型训练与数据中心。
  7. 中国在机器人「身体」制造上领先；让机器人足够智能需要不同于聊天机器人的 AI；美国对手 Skild AI 与 Physical Intelligence 估值已达数十亿美元。

## 4. 胡瀚创业项目细节：雷峰网独家（2026-10-08，早于 Bloomberg 报道）

- **URL**: https://www.leiphone.com/category/ai/rMAfd0hlFnaS8F3t.html
- **标题**: 独家丨前腾讯混元技术骨干胡瀚创业新进展：目标估值数亿美金
- 事实：
  1. 胡瀚创业项目方向**聚焦多模态**，计划融资数千万美元，**目标估值数亿美金**；远识资本担任本轮融资 FA。
  2. 过去一个月已有多家投资机构与胡瀚接触；商业化是机构反复追问的问题。
  3. **关键细节**：胡瀚对未来商业化的答案与多数团队不同——据投资人转述，**他认为其模型未来可以出售给大型科技公司，例如 DeepSeek**。
  4. 胡瀚此前负责腾讯混元视觉大模型算法中心；2026 年 3-4 月其业务线从薄列峰体系划入姚顺雨体系；2026 年 7 月市场传出其计划离职创业。
- 胡瀚学术背景（补充来源）：2008 年清华大学本科、2014 年清华大学博士；**Swin Transformer 核心作者**（《Swin Transformer: Hierarchical Vision Transformer using Shifted Windows》）；曾任职微软亚洲研究院、百度；2025 年 1 月加入腾讯。

## 6. GPT-6 具身能力与压力（多方独立来源）

- 事实：
  1. **GPT-6 Astra 在一项机器人控制任务中成功率 95%，高于 Fable 5.1 的 40%**；同时输出 token 少 6.2 倍、成本低 2.3 倍。（Jay Chooi on X, 2026-09-05 https://x.com/chooi_jeq/status/2096064315115839904 ；机器之心转述）
  2. Robocurve 在 GPT-6 Astra 发布后第二天将其直接接入机器人执行任务，发现控制能力强、Token 消耗低。（机器之心，2026-09-20；转载：虎嗅 https://www.huxiu.com/article/4892584.html 、投资界 https://news.pedaily.cn/202609/569482.shtml ）
  3. 另一派观点（同期报道标题）：「用 GPT-6 Astra 就能直接控制机器人？可具身真机没那…」——真机落地仍有差距。
  4. **Stanford The Movement Lab + Caltech HomeBody 项目（2026-09-30）**：把 GPT Astra 接进**宇树 G1**，机器人先自主探索陌生厨房，再执行找东西、拿药、扔垃圾、开抽屉等连续任务。架构为分层：Astra 只做任务理解、技能选择与失败重决策（结构化 tool call），导航/轨迹规划/碰撞检测/视觉伺服/全身控制仍在机器人本地运行；本地控制 250Hz、AMO 50Hz、Astra 远端推理秒级。（雷峰网 https://www.leiphone.com/category/ai/AVV9SvszqpZ3u8vU.html ）
  5. HomeBody 工程边界：Real2Sim 增加部署准备与 API 成本；Astra 远端推理在技能间产生停顿；本地感知与规划需一台 RTX 4090 笔记本；技能库覆盖范围决定能力上限（技能库没有擦桌子，就无法靠上层规划获得）。
