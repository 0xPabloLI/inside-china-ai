## 一、TikTok 算法底层逻辑（2026 版）

### 1. 核心排名信号

TikTok 算法通过三类信号决定内容分发权重，2026 年的层级如下：

| 信号类型     | 具体指标                                                              | 权重     |
| ------------ | --------------------------------------------------------------------- | -------- |
| **用户互动** | 观看时长、完播率、重播、分享、收藏、评论、关注                        | **最高** |
| **视频信息** | Caption 关键词、Hashtag、Sound/音乐、特效、On-screen text、语音转文字 | **中等** |
| **用户信息** | 语言、国家、设备类型、时区                                            | **较低** |

**2026 年信号权重细化**（综合 Hootsuite + Sprout Social）：

- **最强信号**：观看时长、完播率、重播、分享
- **强信号**：收藏（Save）、评论、从视频引发的关注
- **中等信号**：点赞、Hashtag 互动
- **弱信号**：设备类型、语言、位置

> **关键洞察**：Sprout Social 2026 年报告指出，**收藏和分享的权重已显著超过简单点赞**。这意味着让用户"想保存"或"想转发"的内容比单纯"好看"的内容获得更多分发。

### 2. 2026 年算法新变化

| 变化                        | 影响                                                                   | 应对策略                                          |
| --------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------- |
| **搜索成为更大发现渠道**    | 84% 的 TikTok 搜索发生在探索阶段；57% 用户使用搜索功能                 | Caption、on-screen text、语音转文字都需嵌入关键词 |
| **长视频获得更多分发**      | 1-3 分钟视频若保持高完播率，获得更多推荐；60-90 秒视频常获得更高 reach | 若内容能撑住注意力，不要怕做长                    |
| **TikTok Shop 信号纳入**    | 商业标记内容可出现在购物 feed，获得额外分发                            | 电商内容合理使用产品标记                          |
| **内容多样性优先**          | 算法主动避免连续展示重复内容                                           | 内容格式和话题保持多样性                          |
| **STEM feed 扩展**          | 教育和科学内容有专属发现渠道                                           | 知识类内容可利用 #Science、#STEMTok               |
| **Creator Rewards Program** | 合格观看 = 至少 5 秒（搜索来源需 30 秒）；仅限特定国家                 | 前 5 秒必须留住人                                 |

### 3. 算法"不看"的因素

TikTok 算法**不直接考虑**以下因素：

- **粉丝数量** — 即使你只有 10 个粉丝，视频一样可以爆
- **历史上是否有过爆款** — 每条视频独立评判

> **与源材料的对齐**：源材料提到"好作品在哪里都能爆"——TikTok 算法的设计正是如此。但源材料也警告"账号会脏"——如果历史内容数据差，算法会记住这个号。这与 TikTok 不看"历史爆款"并不矛盾：算法不看你是否爆过，但**会看你的历史内容是否没人看**。

### 4. 算法不推荐的内容类型

以下内容**不合规推荐至 For You 页**（综合 Hootsuite + Later + TikTok 官方）：

| 类别 | 具体内容                                                 |
| ---- | -------------------------------------------------------- |
| 安全 | 未满 16 岁创作的内容、危险活动/挑战                      |
| 暴力 | 仇恨言论、惊悚和图形内容                                 |
| 身体 | 饮食障碍和身体形象、裸露和暴露、性暗示内容               |
| 诚信 | 虚假信息、虚假互动（如"互赞"）、非原创内容（带水印/GIF） |
| 违规 | 赌博、推广烟草或毒品、过度饮酒                           |
| 引流 | 以引导用户离开平台为主要目的的 Live 内容                 |
| 质量 | 重复内容、垃圾内容、QR 码内容                            |

## 二、发视频技巧：如何获得更多流量

### 技巧 1：前 3 秒钩子（最重要的单一技巧）

**所有来源一致认为这是 TikTok 第一法则。**

- TikTok 官方建议前 3 秒内：以问题开场、倒计时/倒数、闪现最终结果预览
- 观众在 2-3 秒内决定是否滑走
- 前 3 秒的观看时长是最强排名信号
- **不要自我介绍** — "很多人想介绍自己，但观众不感兴趣，他们希望你直接切入正题"（Kenzie Epperson, Content Bar）
- **在钩子中制造好奇心或争议** — "在钩子里制造某种争议总是好的"（Kenzie）

**实操**：

- 以惊人事实开场
- 以反直觉的问题开场
- 以挑战常识的声明开场
- 闪现最终成品的画面（"别喝它！！" → Poppi 的 56K 点赞案例）

> **与源材料对齐**：源材料的"第一层·钩子"完全适用。源材料强调"第一个画面绝对不能普通"——在 TikTok 上更是如此，前 3 秒决定生死。

### 技巧 2：找到你的社区（Niche/Community）

- TikTok 的 For You 页**围绕社区构建**，不像 Facebook 以已有好友为主
- 通过 Hashtag 找到社区：#BookTok、#SportsOnTikTok、#Science、#STEMTok 等
- 76% 的 TikTok 用户喜欢品牌参与特殊兴趣小组
- 在一个垂直领域持续发布，算法会认定你的"专家身份"，分发给对应受众

**实操**：

- 使用 TikTok Audience Insights 找到目标受众最活跃的 Hashtag
- 也看"Bottom 10"兴趣，避免做那些类别
- 持续在同一领域发布，给算法足够的信号做分类

> **与源材料对齐**：源材料的"品类 A：热点+大咖解读"——在 TikTok 上就是找到你的垂直社区，然后做这个社区的热点解读。

### 技巧 3：TikTok SEO（关键词优化）

2026 年搜索是更大的发现渠道，**TikTok 已部分成为搜索引擎**。

- 关键词出现在 4 个位置：Caption、on-screen text、语音转文字（auto-captions）、Hashtag
- 使用 Google Ads Keyword Planner 找到未饱和的垂直关键词
- TikTok Creative Center 可按地区和行业搜索热门关键词
- TikTok SEO 的额外好处：可能让你的内容出现在 ChatGPT 等 AI 工具的回答中

**实操**：

- 在 on-screen text 中直接写出目标搜索词："This is the best product for acne, for girls that are 22 years old"
- Caption 中嵌入自然语言关键词，不是堆砌
- 语音中说出关键词——TikTok 会自动转录分析

### 技巧 4：高质量 TikTok-first 内容

- TikTok 内部数据：高质量创作者获得 **72% 更多观看时长**和 **40 倍以上粉丝增长**
- 79% 的用户偏好理解 TikTok 内容特性的品牌
- **不需要精良设备** — TikTok 研究显示受众偏好"不太打磨、真实的美学"
- 必需： decent lighting、good microphone、quick edits/transitions

**关键要素**：

- **字幕/文字叠加** — 超过 30% 的用户静音观看，没有字幕就丢失 1/3 潜在观众
- **TikTok 原生特效** — 使用 TikTok 内置特效让内容感觉"原生于平台"
- **尝试不同画幅** — 竖版优先，但横版也可（全屏播放，适合桌面端）
- **尝试不同长度** — 15-30 秒起步，但 60-90 秒可获得更高 reach

### 技巧 5：发布节奏与时机

| 来源                | 建议                                                         |
| ------------------- | ------------------------------------------------------------ |
| Shopify/Dash Social | **不要日更** — 每周少于 6 次的品牌 FYP 互动高 63%            |
| Hootsuite           | 最佳发布时间：周四上午或周六中午（通用）；但需按自身受众调整 |
| Sprout Social       | 周中下午到傍晚 2-6 PM 为最佳时段                             |
| 源材料              | "不要日更" — 三天干不完说明立项有问题                        |

**核心原则**：

- **质量 > 数量** — 美国 Girl 品牌每周只发 2-3 次，重叙事而非数量
- **一致性 > 频率** — 算法偏好活跃账号，但低质量刷量反而有害
- **可持续节奏** — 找到你能持续产出高质量内容的节奏

### 技巧 6：参与 Trends 和 Trending Audio

- 趋势内容已经在共鸣中，参与它 = 借势获得更广 FYP 分发
- Trending Audio 是 TikTok 算法的分类信号
- 越早参与趋势越好——在音频刚起势时切入效果最佳
- 使用 TikTok Creative Center 发现热门 Hashtag、Song、Creator

**注意**：

- 商业账号使用 approved for business 的音乐
- 保持品牌调性，不要为了蹭热点而偏离定位

### 技巧 7：使用 Duet、Stitch 和 LIVE

- Duet 和 Stitch 是 TikTok 独有的互动格式，算法给予额外分发
- LIVE 可以同步推送到 For You 页
- 与其他创作者合作 → 互相 tag → 观众互相导流

### 技巧 8：Hashtag 策略

- Hashtag = 关键词，告诉算法你的内容关于什么
- 混合使用：宽泛社区标签（如 #BookTok）+ 垂直细分标签
- 参与热门 Hashtag Challenge 可以获得额外曝光
- **不要只靠 Hashtag** — 2026 年关键词优化的权重已等于或超过 Hashtag

### 技巧 9：不要删除旧内容

- TikTok 视频可以在发布**数天甚至数周后**才爆
- 如果一条爆了，旧内容就是观众刷你主页时的存货
- DJ @koozebane 2021 年发的视频在 2022 年才爆并引发趋势

### 技巧 10：建立可重复系列（Content Engine）

- 从"追求单条爆款"转向"建立内容引擎"
- 可重复的系列 = 可持续的生产线
- 例如：回应顾客评论系列、"Day X of teaching you..." 系列
- **测试 > 完美** — 不断测试不同钩子、格式、话题、叙事方式

### 技巧 11：出镜说话

- Pew Research：最受欢迎的创作者 40% 的视频包含说话，最不受欢迎的仅 20%
- 说话 = 语音转文字 = 更多 SEO 信号 = 更多分类信号
- 出镜讲故事比纯营销更有感染力

### 技巧 12：添加购买路径

- 流量不转化 = 无意义
- 引导观众到产品页、邮件列表、TikTok Shop
- 创作者可用 Shopify Starter 创建简单在线店面

## 三、发视频注意事项：如何不被系统 Ban

### 1. Shadowban 是什么

Shadowban = 你的视频**不出现在 For You 页**，但账号看似正常。

**症状**：

- 每条新视频获得 **0 播放**（或从原来的 1000+ 暴跌到 0）
- 点赞、评论、分享急剧下降
- 用一个不常见的 Hashtag（如 #test13579）发视频，让朋友搜索该标签——如果搜不到，就是被 shadowban 了

### 2. 被 Ban 的五大原因及预防

| 原因             | 详细说明                                                     | 预防措施                      |
| ---------------- | ------------------------------------------------------------ | ----------------------------- |
| **操作过快**     | 关注、点赞、评论、分享、上传速度太快，算法判定为 bot         | 像正常人一样使用，不批量操作  |
| **低质量内容**   | 转发内容、几乎无编辑、无吸引力                               | 发布前与 FYP 上的内容对比质量 |
| **违反社区准则** | 危险内容、非法内容、图形内容等（见上文"不推荐内容"完整列表） | 仔细阅读 Community Guidelines |
| **购买假数据**   | 买粉丝、买赞、买评论、买分享                                 | 绝不购买任何虚假互动          |
| **使用 VPN**     | VPN 改变地理位置，算法检测到后限制分发                       | 不使用 VPN，用本地网络        |

### 3. 2026 年防封禁完整清单

#### 内容层面

- [ ] 不发布带水印的内容（包括其他平台 logo）
- [ ] 不发布纯 GIF 或非原创内容
- [ ] 不发布危险挑战/特技内容
- [ ] 不发布仇恨言论或歧视性内容
- [ ] 不发布裸露或性暗示内容
- [ ] 不发布虚假信息或未经证实的选举/公民诚信声明
- [ ] 不发布推广烟草、毒品、过量饮酒的内容
- [ ] 不发布赌博内容
- [ ] 不以引导用户离开平台为主要目的做 Live
- [ ] 不发布饮食障碍或负面身体形象内容

#### 行为层面

- [ ] 不批量关注/取关（Spam 行为）
- [ ] 不批量点赞/评论
- [ ] 不短时间内上传大量视频
- [ ] 不购买任何虚假互动（粉丝、赞、评论、分享）
- [ ] 不使用 VPN
- [ ] 不在简介中过早放链接（建议 1000 粉后再加）
- [ ] 不在评论区发广告

#### 设备层面

- [ ] 一台设备不同时运行多个账号（或使用云手机/指纹浏览器隔离）
- [ ] 不使用被封过的设备直接注册新号（需彻底刷机+换网络）
- [ ] IP 归属地与目标运营国家一致，不频繁跳动

### 4. 如果已经被 Shadowban

| 方法                    | 说明                                                                       |
| ----------------------- | -------------------------------------------------------------------------- |
| **等待**                | Shadowban 通常持续 1-2 周后自动解除                                        |
| **继续正常发布**        | 继续发高质量内容 + 正常互动 FYP，向算法证明你不是 bot                      |
| **提交 Support Ticket** | Profile > Menu > Settings and privacy > Report a problem > Submit a report |
| **创建新号**            | 如果 2 周后仍未解除，可能 SIM 卡被拉黑，需新手机+新 SIM 卡                 |

**判断是否被 ban**：

- 如果新视频发布后几小时仍有 50-300 播放 → **没有被 ban**，只是内容不够好
- 如果新视频持续 0 播放 → **很可能被 ban**

> **与源材料对齐**：源材料提到"账号会脏"——在 TikTok 上，shadowban 就是"脏号"的一种表现。源材料的结论"要么重开新号，要么放弃"在 TikTok 上尤其正确，因为 SIM 卡被拉黑后几乎无法挽回。

## 四、TikTok 养号全流程

### 核心原理

**养号 = 在发布内容前，向算法证明你是一个真人，并训练算法对你的账号打上正确的垂直标签。**

TikTok 对新账号的风控强度是成熟账号的 **23 倍**（据 TikTok Creator Academy 数据）。养号期通过模拟真实用户行为，打破冷启动限流。

### 养号周期

| 账号类型       | 养号周期     | 来源                                         |
| -------------- | ------------ | -------------------------------------------- |
| 新注册账号     | **7-14 天**  | Google AI Overview / 360° Uniquizer / IpStar |
| 购买的历史账号 | **5-7 天**   | 360° Uniquizer                               |
| 严格风控区域   | **10-14 天** | IpStar                                       |

> 3 天是最低限度的"受控准备检查"（TokPortal）；7 天是推荐的最短有效养号期（Conbersa）；10-14 天为安全上限。

### Phase 1：环境搭建与纯浏览（Day 1-2）

#### 环境准备（注册前）

| 项目      | 要求                                       | 原因               |
| --------- | ------------------------------------------ | ------------------ |
| 网络      | IP 归属地与目标运营国一致，不使用高风险 IP | 算法检测 IP 一致性 |
| 设备      | 干净设备，独特硬件指纹，本地运营商连接     | 避免设备关联       |
| SIM 卡    | 拔掉手机 SIM 卡（或用目标国原生卡）        | 防止 SIM 卡关联    |
| 定位      | 关闭定位服务                               | 防止地理位置泄漏   |
| 语言/时区 | 调整为目标国家标准                         | 一致性信号         |
| 多账号    | 一台设备一个账号                           | 防关联             |

#### Day 1-2 操作

| 操作       | 具体做法                                               |
| ---------- | ------------------------------------------------------ |
| 完善资料   | 头像、昵称、Bio 简介（关键词优化，但**不放联系方式**） |
| 浏览 FYP   | 每天 15-20 分钟，让视频自然播放或自然滑过              |
| **不互动** | 不点赞、不评论、不编辑资料                             |

### Phase 2：垂直训练与轻度互动（Day 3-5）

| 操作           | 具体做法                                                   |
| -------------- | ---------------------------------------------------------- |
| 搜索垂直关键词 | 在搜索栏输入你计划做的领域关键词（如 AI、科技、中国新闻）  |
| 观看垂直内容   | 完整观看同类视频，让算法明确你的兴趣标签                   |
| 轻度互动       | 每天点赞 5-10 个相关帖子，收藏 2-3 个，关注 2-3 个头部大号 |
| 完善资料       | 更新头像（如有需要），写干净的、关键词优化的 Bio           |
| **仍不做**     | 不大量互动、不批量操作、不发视频                           |

### Phase 3：完播与试探发布（Day 6-7+）

| 操作         | 具体做法                                           |
| ------------ | -------------------------------------------------- |
| 模拟正常习惯 | 继续有机浏览，在竞品/垂直视频下留几条有思考的评论  |
| 关注头部大号 | 关注 3-5 个同领域的头部大号，模仿他们的互动频率    |
| **首次发布** | 直接从手机 app 发布第一条原创、高完播率的视频      |
| 监控流量     | 观察是否能突破 200-500 的初始流量池                |
| 逐步加量     | 如果首条有播放，逐步增加发布频率，但仍保持质量优先 |

### 防风控要点（养号期间禁忌）

| 禁忌                         | 原因             |
| ---------------------------- | ---------------- |
| 不在简介留联系方式           | 营销行为触发风控 |
| 不在评论区发广告             | 同上             |
| 不短时间高强度自动点赞       | 类 bot 行为      |
| 不使用被封过的设备直接注册   | 设备指纹关联     |
| 每天刷视频时间分散在早/中/晚 | 模拟真人使用节奏 |
| 不频繁切换 IP/网络           | 地理一致性       |

### 养号期间的时间分配建议

```
Day 1-2:  每天 15-20 分钟纯浏览 FYP
Day 3-5:  每天 30-40 分钟（搜索+浏览+轻互动）
          - 搜索垂直关键词 5 分钟
          - 完整观看同类视频 15-20 分钟
          - 点赞 5-10 个、收藏 2-3 个、关注 2-3 个
Day 6-7:  每天 40-60 分钟（浏览+互动+首条发布）
          - 继续浏览和互动
          - 在竞品下留 2-3 条有质量的评论
          - 发布第一条原创视频
Day 8+:   正常运营节奏（每周 3-5 条高质量内容）
```

> **与源材料对齐**：源材料提到"跨平台投流：好作品在哪里都能爆"——但前提是号是干净的。养号就是这个前提的准备过程。源材料也说"B 站旧号脏了可能要新开一个号"——TikTok 同理，如果旧号被 shadowban，不如养新号。

## 五、内容公式在 TikTok 上的落地

源材料的四层公式 **钩子 → 共情 → 获得感 → 升华** 在 TikTok 上的具体落地：

### 第一层 · 钩子（前 3 秒）

| 源材料原则               | TikTok 落地                                                                                                                   |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| "封面给眼球，标题给算法" | TikTok 没有 traditional 封面，但**第一帧 = 封面**。前 3 秒的视觉冲击 = 封面。Caption + on-screen text + 语音 = 标题（给算法） |
| "第一个画面绝对不能普通" | 第一帧必须有视觉冲击：铺满的画面、对比强烈的色彩、出人意料的画面                                                              |
| "前 10 秒要额外设计"     | TikTok 上是前 3 秒。更多的梗图、钩子、视觉冲击压缩到 3 秒内                                                                   |

### 第二层 · 共情（3-15 秒）

| 源材料原则                       | TikTok 落地                                         |
| -------------------------------- | --------------------------------------------------- |
| "让观众感觉你和我是一伙的"       | 出镜说话（40% vs 20% 数据支持），用对话感而非说教感 |
| "不是讲道理，是讲我也有这个困惑" | 用 "you" 而非 "I" 开头，让观众觉得你在说他们的事    |

### 第三层 · 获得感（15-45 秒）

| 源材料原则                   | TikTok 落地                                                                    |
| ---------------------------- | ------------------------------------------------------------------------------ |
| "我关注你是有好处"           | 提供"学到了"、"被理解了"、"看到不同角度"的任何一个                             |
| "不一定是干货，情绪共鸣也算" | 好看本身也是获得感。但要让观众**想保存或分享**——2026 年 Save 和 Share 权重最高 |

### 第四层 · 升华（45 秒+）

| 源材料原则                                | TikTok 落地                                                          |
| ----------------------------------------- | -------------------------------------------------------------------- |
| "让钩子变强、共情变深、获得感变厚"        | 结尾给出新视角，让观众觉得"关注你真的有用"                           |
| "检验标准：连几万播放都没有 → 方法论错了" | TikTok 上：如果 FYP 播放持续低于 200，不是号的问题就是内容方法论问题 |

### 源材料"四条实操法则"在 TikTok 的映射

| 法则                       | TikTok 落地                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **封面给眼球，标题给算法** | 第一帧给眼球（视觉冲击），Caption + on-screen text + 语音给算法（SEO 关键词）                                 |
| **一鱼多吃**               | TikTok 适合竖版（或 4:3 折中），但每个平台的封面/标题需单独做。TikTok 版 ≠ 抖音版 ≠ YouTube 版                |
| **不要日更**               | 每周少于 6 次的品牌 FYP 互动高 63%。质量优先                                                                  |
| **元素迭代法**             | 每轮只换一个元素（钩子类型、BGM、出镜/不出镜、长度），用数据说话。TikTok Analytics 提供观看时长、完播率等数据 |

## 附录：TikTok 发视频 Checklist

### 发布前

- [ ] 前 3 秒有强钩子（问题/反直觉/视觉冲击）
- [ ] 第一帧不普通
- [ ] Caption 包含 SEO 关键词
- [ ] On-screen text 包含搜索关键词
- [ ] 有字幕（30% 用户静音观看）
- [ ] 使用 trending audio（如适用）
- [ ] Hashtag：1-2 个社区标签 + 2-3 个垂直标签
- [ ] 内容不违反社区准则（对照"不推荐内容"列表）
- [ ] 质量与 FYP 上的内容相当或更好
- [ ] 长度合适（15-30 秒起步，可试 60-90 秒）

### 发布后

- [ ] 在前 30 分钟内积极回复评论（互动信号）
- [ ] 监控前 1 小时播放数据
- [ ] 如果 0 播放 → 检查是否 shadowban
- [ ] 如果 50-300 播放 → 内容不够好，迭代改进
- [ ] 记录数据用于元素迭代法

### 不做

- [ ] 不买假数据
- [ ] 不用 VPN
- [ ] 不批量操作
- [ ] 不带水印/非原创
- [ ] 不为了发而发
- [ ] 不删除旧视频
