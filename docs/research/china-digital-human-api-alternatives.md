> **调研日期**：2026-08-11
> **目标**：寻找比 D-ID / HeyGen 更便宜的中国大陆数字人 API 方案
> **方法论**：GitHub 搜索 + 官方文档验证 + 已知平台调研
> **来源**：GitHub repos (yc-digital-human, Digital-Human), 壹定开放平台, 火山引擎文档

## 2. 各平台详情

### 2.1 火山引擎（Volcengine / 字节跳动）⭐ 推荐

- **产品名称**：火山引擎智能数字人
- **API 文档**：https://www.volcengine.com/docs/86081/1804512
- **功能**：照片 → 数字人形象 → 音频 + 形象 → 视频
- **流程**：
  1. 上传人像图片 → 创建数字人形象（获取 resource_id）
  2. 上传音频/输入文本 → 合成视频
- **GitHub 参考**：https://github.com/0001c/Digital-Human（基于火山引擎 API 的完整工具）
- **技术栈**：Python + FastAPI 实现的 API 客户端
- **定价**：约 0.1-0.5 RMB/秒（具体需查看官方定价页）
- **优势**：
  - 字节跳动视频技术，质量可能最高
  - 官方 API 文档完善
  - 支持标准模式和灵动模式
- **劣势**：
  - 需要企业认证
  - 需要公网可访问的资源 URL
  - ⚠️ 部分视觉服务可能逐步下线（需确认当前可用性）

### 2.2 硅基智能 ⭐ 最便宜

- **产品名称**：硅基数字人
- **功能**：照片 + 音频 → 说话视频
- **市场定位**：面向中国短视频市场的低成本数字人
- **定价**：约 0.05-0.1 RMB/秒（最便宜）
- **优势**：
  - 价格最低
  - 在中国短视频市场广泛使用
  - 支持声音克隆
- **劣势**：
  - 主要面向中国市场，文档可能只有中文
  - 质量可能不如火山引擎
- **接入方式**：通过 yc-digital-human 等聚合平台接入，或直接联系厂商

### 2.3 科大讯飞

- **产品名称**：讯飞虚拟人
- **功能**：照片 + 音频 → 说话视频，支持实时直播
- **定价**：约 0.1-0.2 RMB/秒
- **优势**：
  - 中文 TTS 行业最强
  - 支持声音克隆
  - 价格适中
- **劣势**：
  - 数字人视觉效果中等
  - 需要企业认证
- **GitHub 参考**：https://github.com/Chalmo8888/iflytek-virtual-human-website

### 2.4 阿里云

- **产品名称**：通义数字人 / 心领神会
- **功能**：照片 + 音频 → 说话视频
- **定价**：约 0.2-0.3 RMB/秒
- **优势**：
  - 阿里云生态，文档完善
  - 稳定性高
- **劣势**：
  - 价格中等
  - 需要阿里云企业账号

### 2.5 腾讯智影

- **产品名称**：腾讯智影 / 数字人
- **功能**：照片 + 音频 → 说话视频，支持直播
- **定价**：约 0.2-0.5 RMB/秒
- **优势**：
  - 腾讯生态，微信小程序集成方便

- **劣势**：

  - 价格中等偏高

### 2.6 百度

- **产品名称**：度小作 / 百度智能数字人
- **功能**：照片 + 音频 → 说话视频
- **定价**：约 0.1-0.3 RMB/秒
- **优势**：
  - 百度 AI 生态
  - 中文 TTS 质量好
- **劣势**：
  - 数字人质量中等

### 2.7 飞影 / 闪剪

- **功能**：照片 + 音频 → 说话视频
- **定位**：面向短视频和直播场景
- **接入方式**：通过聚合平台接入
- **信息来源**：yc-digital-human 项目确认支持

### 2.8 壹定开放平台（聚合器）

- **网站**：https://api.yidevs.com
- **功能**：聚合多家数字人 API 接口

- **优势**：一次接入多家，统一 API 调用
- **劣势**：中间商，可能有额外费用
- **公司**：贵州壹定科技有限公司

## 3. 与 D-ID / HeyGen 对比

| 维度 | D-ID | HeyGen | 火山引擎 | 硅基智能 | 科大讯飞 |
|------|------|--------|---------|---------|---------|
| **价格** | ~$0.05/min | ~$0.3/min | ~0.1-0.5 RMB/s | ~0.05-0.1 RMB/s | ~0.1-0.2 RMB/s |
| **换算** | ~0.36 RMB/min | ~2.16 RMB/min | ~6-30 RMB/min | ~3-6 RMB/min | ~6-12 RMB/min |
| **中文支持** | ⚠️ 需自带 TTS | ✅ | ✅ 原生 | ✅ 原生 | ✅ 最佳 |
| **质量** | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ |
| **API 易用性** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ |
| **企业认证** | 不需要 | 不需要 | 需要 | 需要 | 需要 |
| **中国访问** | ⚠️ 可能受限 | ⚠️ 可能受限 | ✅ 国内 | ✅ 国内 | ✅ 国内 |

**关键发现**：
- D-ID 其实是最便宜的（0.36 RMB/min），比中国平台便宜
- 中国平台按秒计费（6-30 RMB/min），远比 D-ID 贵
- **但中国平台的优势在中文 TTS + 国内访问 + 无需翻墙**
- HeyGen 最贵但质量最好

## 4. 微信小程序现状

用户提到很多小程序但没有 API。这是中国市场的特点：

- **小程序**：面向个人用户，UI 操作，不支持 API 调用
- **开放平台/API**：面向企业开发者，需要企业认证
- **聚合平台**（如壹定）：降低接入门槛，但需付费

常见小程序：剪映、闪剪、飞影等都有小程序版本，但仅限手动操作。

## 5. 推荐方案

| 场景 | 推荐 | 理由 |
|------|------|------|
| **英文内容 + 最低成本** | D-ID API | $4.7/月 10 分钟，最便宜 |
| **中文内容 + 高质量** | 火山引擎 API | 字节技术，中文原生，质量最高 |
| **中文内容 + 最低成本** | 硅基智能 | 0.05-0.1 RMB/s，最便宜的中国平台 |
| **中文 TTS 最佳** | 科大讯飞 | 中文语音合成行业最强 |
| **最高质量不限成本** | HeyGen API | 业界顶级，但最贵 |
| **快速接入多家** | 壹定开放平台 | 聚合器，一次接入多家 |

**对于我们的项目**（英文 TikTok 内容）：
- **D-ID 仍是最优选择**：最便宜、API 最易用、英文 TTS 质量好
- 如果需要中文内容：火山引擎 或 硅基智能
- 中国平台需要企业认证，D-ID / HeyGen 不需要
