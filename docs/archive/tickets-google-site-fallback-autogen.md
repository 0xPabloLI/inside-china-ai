# Tickets: #88 Part 2 — Universal Google `site:` Fallback Auto-Generation

## T1 — Auto-gen functions, exclusion logic, and enrichWithCapabilities integration

**What to build:** When `enrichWithCapabilities()` processes sources, applicable sources (those without explicit `googleSiteFallback`, without `apiSearch`, without `mcpFallback`, not search engines, not image libraries) get an auto-generated `googleSiteFallback` derived from their URL domain. The auto-generated config uses a shared Google `h3` extractor script. This makes Google `site:` search available as a fallback for 13 sources that previously had no intermediate fallback between CDP failure and MCP/empty.
