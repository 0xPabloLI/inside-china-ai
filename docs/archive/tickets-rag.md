### T-02: Update CONTEXT.md — RAG Terminology

**Status**: ✅ Complete (pre-existing)
**Depends on**: None
**Effort**: 15 min

Add RAG-related terms to `CONTEXT.md`.

**Terms to add**:
- **Embedding**: A vector representation of text content, generated by bge-m3 (1024 dimensions). Used for semantic similarity search.
- **Chunk**: A semantically coherent unit of content (typically one `##` section or one scene) that gets its own embedding. Identified by `(content_type, source_id, chunk_index)`.
- **Vector Search**: Retrieving content by computing cosine similarity between query embedding and stored embeddings. Performed by `match_content` RPC function.
- **Reranker**: Optional second-stage ranking model (bge-reranker-base) that reorders vector search results. Disabled by default; enabled via `--rerank` flag.
- **Golden Query**: A hand-curated test query with known expected results, used to evaluate retrieval quality. Stored in `docs/refs/rag-eval/golden-queries.yaml`.
- **Orphan Cleanup**: Post-index step that deletes embeddings whose `source_id` no longer corresponds to any content file.

**Acceptance Criteria**:
- [x] Terms added to CONTEXT.md under new `## RAG Pipeline` section
- [x] Each term has `_Avoid_` entry (per existing format)
- [x] No existing terms modified
