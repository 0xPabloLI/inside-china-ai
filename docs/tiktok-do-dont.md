# TikTok 短视频：Do / Don't 对比指南

> 基于 2025-2026 年最新行业数据。完整数据来源见 `tiktok-best-practices.md`。

---

## 🔴 Hook（前 3 秒）

| ✅ DO | ❌ DON'T |
|-------|---------|
| 前 3 秒用震撼数据/问题/预览抓住注意力 | 用冗长开场白慢慢引入 |
| 问一个视频会回答的问题 | 做企业宣传式的自我介绍 |
| 闪烁预览最终结果 | 让观众猜视频在讲什么 |
| 用倒计时/计时器制造紧迫感 | — |

**我们的状态**：Scene 1 用了 "A leaked four-hour investor meeting just paused DeepSeek's $1.4B funding round" — 这是一个好的 hook ✅

---

## ⏱ 时长

| ✅ DO | ❌ DON'T |
|-------|---------|
| TikTok 版本控制在 **60-70 秒**（故事叙述型） | 做超过 90 秒的长视频 |
| 或者做 **5-12 秒**超短循环视频 | 试图把所有信息塞进一个视频 |
| 让人想**保存**或**重播**的内容 | 信息密度太低让人中途划走 |
| 确保高完成率（看完比例） | 只关注总观看量 |

**我们的状态**：当前 170 秒 ❌ 需要为 TikTok 做精简版

---

## 📝 字幕 & 文字

| ✅ DO | ❌ DON'T |
|-------|---------|
| 加字幕（可达性 + 参与度） | 不加字幕让观众猜 |
| 关键词出现在**屏幕文字 + 口播 + 字幕**中 | 把关键词藏在屏幕外（无效） |
| 数字和数据用视觉强调 | 纯文字叙述数字 |
| Pattern Interrupts（快速切换、文字叠加） | 画面一成不变 |

**我们的状态**：字幕已修复（Scene 1 也有字幕了）✅

## 🔍 SEO & 发现

| ✅ DO | ❌ DON'T |
|-------|---------|
| 关键词放屏幕文字、口播、描述中 | 只用 #FYP 等通用标签 |
| 3-5 个 hashtag（大类 + 小众混合） | 堆砌 10+ 个标签 |
| 加地理标签（China/US） | 忽略地理标签 |
| 用 Creator Search Insights 找内容缺口 | 凭感觉猜用户想看什么 |
| TikTok 视频也被 Google 索引 — SEO 双重收益 | — |

## 🎵 音频

| ✅ DO | ❌ DON'T |
|-------|---------|
| 使用趋势音频/音乐 | 完全静音或用原创音乐 |
| 在 TikTok 音频库中选热门音乐 | 用版权受限的音乐 |
| 口播清晰自然 | 机械感重的 AI 声音（如果太明显） |

**我们的状态**：用 XTTS 克隆声音 + BGM ✅（声音克隆已验证）

---

## 📅 发布

| ✅ DO | ❌ DON'T |
|-------|---------|
| 每周发 3-5 次 | 一周发 1 次然后消失 |
| 非高峰时段发布（竞争少） | 只在所有人都在发的高峰时段发 |
| 发布后前 1 小时回复评论 | 发完就走 |
| 保持一致的风格和频率 | 忽高忽低 |

---

## 🎨 内容风格

| ✅ DO | ❌ DON'T |
|-------|---------|
| 真实、随意、像和朋友说话 | 做精致的企业宣传片 |
| 有签名风格（一眼认出是你） | 每个视频风格都不一样 |
| 做系列内容（让人追更） | 随机发不相关的内容 |
| 回答评论区的 FAQ | 忽略观众的问题 |
| 跟趋势但加自己的风格 | 盲目复制趋势 |
| 填补同领域的内容需求 | 做没人搜的内容 |

## ⚠️ 禁止事项（算法不会推荐）

| ❌ 绝对不要 |
|------------|
| 带其他平台水印的内容（如 TikTok 上有 Instagram 水印） |
| "Like-for-like"（互相点赞交换的假互动） |
| 简单转载的 GIF 或无原创内容 |
| 引导用户离开平台的 Live 内容 |
| 虚假信息、仇恨言论、危险活动 |

---

### Like-for-like 是什么？

"Like-for-like" 是一种**虚假互动行为**：两个创作者约定互相点赞对方的视频（"你赞我，我赞你"），以人为提高互动数据。TikTok 算法能检测这种行为，并**降低这类内容的推荐**。类似的假互动还包括：

- 互相关注但不看内容
- "关注我，我会关注你" 的承诺
- 用机器人批量点赞/评论
- 购买点赞/粉丝

TikTok 2026 年明确将这类内容列为**不推荐内容**，和带水印、虚假信息同等处理。
