## 🔍 数据分析与诊断

### 核心问题

#### 1. 完播率极低（1.2% 和 0.9%）

- **标准**：TikTok 70% 完播率是 FYP 推荐门槛
- **现状**：不到 2%，远低于门槛
- **原因**：视频时长 2.5 分钟，但平均观看时间仅 6.6s 和 20.7s
- **影响**：算法判定内容不吸引人，大幅限制 FYP 推荐

#### 2. 前 3 秒流失严重

- **数据**：两条视频的观众都在 **0:02** 停止观看
- **含义**：Hook 失效 — 前 2 秒没有抓住注意力
- **根因**：开场可能缺乏视觉冲击力、悬念或明确的价值承诺

#### 3. FYP 流量极低（账号总览仅 5.7%）

- **对比**：单条视频的 FYP 流量为 72-77%，但账号总览 FYP 仅 5.7%
- **解释**：搜索流量在总览中占绝对主导（88.7%），因为 FYP 推荐量绝对值很小
- **计算**：382 总播放 × 5.7% FYP ≈ 22 次 FYP 播放 / 7 天 — 几乎没有 FYP 推送

#### 4. 互动率低

- **赞/播放率**：10/382 ≈ 2.6%（TikTok 平均 3-5%）
- **评论**：0 条评论
- **分享**：1 次
- **收藏**：3 次（视频 1）— 说明部分观众觉得内容有价值

#### 5. 视频标题/描述问题（视频 2）

- 视频 2 用 `#creatorsearchinsights` 开头，标题不够吸引人
- 搜索词 "creator insights part 3 4 5..." 说明标题误导了部分观众

### 正面信号

1. **搜索流量强劲**：88.7% 的流量来自搜索，说明 SEO 关键词布局有效
2. **收藏率**（视频 1）：3/246 ≈ 1.2%，内容对部分观众有价值
3. **视频 2 平均观看时间更高**（20.65s vs 6.63s），但需对比视频内容差异
4. **新增 2 粉丝**：说明内容有转化能力

## 📎 附录：CDP 数据抓取方法

### 前提条件

1. 已加载 web-access skill 并完成 CDP proxy 启动
2. 已登录 TikTok 账号

### 抓取步骤

以下命令假设 CDP proxy 已运行（`localhost:3456`），tab 已通过 web-access 创建并获得 `TAB_ID`：

```bash
# Step 1: 打开总览页
curl -s -X POST --data-raw 'https://www.tiktok.com/tiktokstudio/analytics/overview' http://localhost:3456/new
# 等待 10s 后提取数据
curl -s -X POST "http://localhost:3456/eval?target=TAB_ID" -d 'document.body.innerText'

# Step 2: 打开内容页（获取视频列表）
curl -s -X POST --data-raw 'https://www.tiktok.com/tiktokstudio/analytics/content' http://localhost:3456/new
# 等待 10s 后提取视频列表
curl -s -X POST "http://localhost:3456/eval?target=TAB_ID" -d 'document.body.innerText'

# Step 3: 点击「查看数据」获取单条视频详情
curl -s -X POST "http://localhost:3456/eval?target=TAB_ID" -d 'var btns=document.querySelectorAll("button.TUXButton");for(var i=0;i<btns.length;i++){if(btns[i].textContent.trim()==="查看数据"){btns[i].click();break;}}"clicked"'
# 等待 8s 后提取详情
curl -s -X POST "http://localhost:3456/eval?target=TAB_ID" -d 'document.body.innerText'

# Step 4: 返回列表，点击下一条视频的「查看数据」
curl -s -X POST "http://localhost:3456/eval?target=TAB_ID" -d 'var b=document.querySelectorAll("button.TUXButton");var c=0;for(var i=0;i<b.length;i++){if(b[i].textContent.trim()==="查看数据"){c++;if(c===2){b[i].click();break;}}}"clicked 2nd"'
```

### 注意事项

- CDP 访问 TikTok Studio 有一定风险，但只要不做异常操作（如频繁刷新、批量请求），风险较低
- 每次抓取间隔至少 5 秒，避免被检测为自动化行为
- 抓取完毕后关闭多余的 tab，保持 tab 数量合理
- TikTok Studio Analytics 页面数据会实时更新，建议固定时间抓取（如每周一上午）
