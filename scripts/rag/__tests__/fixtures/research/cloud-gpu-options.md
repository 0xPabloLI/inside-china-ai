# Cloud GPU Options

Research report comparing cloud GPU providers for AI video inference.

## Modal

Modal offers T4 GPUs at $0.59/hour. Suitable for intermittent inference workloads.

## Kaggle

Kaggle provides free T4 GPUs with 30h/week quota. Good for experimentation.

## Colab

Colab Pro+ offers A100 40GB at $9.99/month. Reliable for sustained workloads.
